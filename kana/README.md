# Kana Flashcards

A small local web app for drilling hiragana and katakana recognition.

## Features

- Hiragana and katakana study modes
- Basic kana, dakuten/handakuten, and combination sounds
- Type-to-check romaji answers
- Reveal, known/missed grading, shuffle, and session reset controls
- Responsive layout that works on desktop and mobile

## Run

Install dependencies, then start the Vite dev server:

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
